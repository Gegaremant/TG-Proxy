# Release 1.2.1

## Стабильность (из upstream 1.10.x, применяется на Windows/macOS/Linux)

* **Пул WebSocket-соединений**: рефилл начинается сразу (1с вместо 60с), включён
  fronting-first, расширен бэкофф до 12 попыток; мёртвые соединения чинятся в фоне,
  не блокируя выдачу.
* **Исправлен media-фолбэк** при чередовании медиа-каналов.
* **Фильтр доменов в логах** (`DomainCensorFilter`) — логи не светят чужие домены.

## Порт и конфигурация

* **Случайный порт один раз.** При новой установке выбирается случайный порт
  (49152–65535) и сохраняется в конфиге — при следующих запусках он не меняется.
  Порт, SNI и генерация конфигурации по-прежнему редактируются в настройках.

## Первый запуск

* **Проверка доступности Telegram API** перед показом ссылки `tg://proxy`:
  приложение проверяет TLS-соединение с API Telegram и показывает ссылку только
  после успешной проверки (кнопка «Повторить проверку» при сбое).

## Автозапуск

* **Автозагрузка включена по умолчанию** на Windows (реестр). Отключить — в настройках.

## Интерфейс и иконки

* **Значок «Т» заменён на «КТ»** во всех местах: tray fallback, macOS `.icns`,
  Android launcher (adaptive icon) и иконка уведомления.
* Desktop-иконка переработана: оставлен только кристалл в руках робота, убраны
  белые просветы по бокам, изображение растянуто.

## Сборка

* Версия поднята до **1.2.1** во всех specs (`windows/macos/linux/spec`),
  `version_info.txt`, Android `versionCode=7` и GitHub Actions.
* README: добавлены кнопки-бейджи скачивания для каждой ОС; добавлена инструкция
  по установке на macOS (`MACOS_INSTALL.md`).

# Linux: запуск, автозагрузка и сервис (в разработке)

* Добавлена полноценная поддержка Linux: `install.sh`, пункт меню (`packaging/tg-proxy.desktop`),
  автозапуск GUI при входе (`tg-proxy-autostart.desktop`) и headless-сервис
  (`packaging/tg-proxy.service`) через systemd.
* Собран отдельный headless-бинарник `TG-Proxy-Service` (`packaging/linux-service.spec`)
  без GUI — для работы в фоне как сервис.
* **Проверка запущенного режима.** При запуске приложение определяет, не работает ли прокси
  уже (в GUI-трее или как headless-сервис), сообщает текущий режим (с PID) и предлагает
  переключиться: «остановить сервис и запустить GUI» или наоборот.
* Исправлено падение трея на X11, вызванное эмодзи 🖤 в заголовке (`latin-1` кодировка).
* **Трей на Xfce/GNOME через AppIndicator.** Сборка Linux теперь включает PyGObject (`gi`)
  и `.typelib` GObject, поэтому иконка в системном трее создаётся через AppIndicator
  (`pystray._appindicator`), а не откатывается в неработающий X11-режим. Фикс нужен
  для панелей на основе StatusNotifier (Xfce, GNOME, Cinnamon, MATE).
* Бандлинг библиотек tcl/tk для корректной работы CustomTkinter в собранном бинарнике.

# Release 1.0.5

## Исправление подключения (главное)

* **CF-домены снова работают.** Убран жёсткий подбор IP дата-центров: теперь в режиме Cloudflare прокси идёт в CF-проксированный домен напрямую (как в референсном Rust-прокси), а не на заблокированный `149.154.167.220`.
* Исправлен порядок fallback: `CF-домен пользователя → CF Worker → CF-пул → прямой WebSocket → закрытие с остыванием`.
* Прямой WebSocket теперь умеет повторять попытку соединения через доменное имя (резолвится через DNS), а не только по захардкоженному IP.

## Медиа-каналы

* **Исправлен media-фолбэк.** Для медиа-каналов (DC2 media, DC4 media) теперь используется хост `kws{dc}.{домен}` без суффикса `-1`, как в референсной реализации. Раньше медиа-каналы падали с `UnknownHostException`, потому что хоста `kws{dc}-1.{домен}` не существует.

## DNS-over-HTTPS

* Добавлен резервный резолвер **DoH (DNS over HTTPS)** на случай, когда системный DNS не может разрешить CF-домены.
* Используются публичные DoH-серверы: Cloudflare (`1.1.1.1`), Google DNS (`8.8.8.8`), Quad9 (`9.9.9.9`), AdGuard (`94.140.14.14`) и ваш провайдерский `xbox-dns.ru` (DoH).

## Upstream SOCKS5

* Добавлена поддержка **upstream SOCKS5** (например, Hiddify `127.0.0.1:2334`) — весь исходящий трафик прокси можно пускать через сторонний SOCKS5-прокси.

## Интерфейс

* Новый заголовок главного экрана: **TG FREE with 🖤 From KatYa && Gegaremant**.
* Переключатель **светлой/тёмной темы** прямо в шапке (значок солнца/луны).
* Значок **GitHub** внизу главного экрана (ссылка на репозиторий).
* Кнопка «Отключить оптимизацию батареи» перенесена на главный экран и показывается только если батарея ещё не оптимизирована.
* Убраны пресеты «Дома» и «В метро».
* В ссылке `tg://proxy` и в логах больше не показывается реальный IP адрес устройства — используется стандартный `127.0.0.1` (localhost).
