# Release 1.0.1

* Добавлена поддержка Cloudflare Proxy (CF-прокси) для Android.
* В настройки добавлена возможность указывать свой домен для CF-прокси.
* Исправлена ошибка с постоянными отключениями при выключенном экране (добавлен WifiLock).


# Release 1.0.2

* Добавлен автоконфиг при запуске прокси (выбирает лучший домен).
* Ссылки на подключение к Telegram теперь показываются только если прокси успешно запущен.
